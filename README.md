# \# MSME Credit and Cash-Flow Risk Analyser



A small Python tool that screens small-business borrowers for repayment risk, based on checks I perform manually as a credit officer.



\*\*Status:\*\* work in progress.

\*\*Data.\*\* 100% synthetic. No real customer or bank data is used.



\##Planned features

\- \[x] Generate synthetic borrower data

\- \[ ] Calculate monthly instalment (EMI) and Debt Service Coverage Ratio (DSCR) per borrower

\- \[ ] Assign a risk tier and summarise the portfolio by tier and sector

\- \[ ] Stress-test repayment capacity under a revenue shock





\## How to run

&#x20;   pip install -r requirements.txt

&#x20;   python src/generate\_data.py
